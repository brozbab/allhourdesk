## Asset rules

- Current files are web-optimised concept previews.
- Do not treat generated text or metrics inside these visuals as approved product claims.
- Real product screenshots should replace concept UI over time.
- Do not publish generated customer identities, fake testimonials or fabricated performance numbers.
- Maintain the same warm bone / oxblood / ink visual system for all future assets.
- Prefer 4:3 for standalone marketing diagrams; use responsive HTML/SVG for production text-heavy workflows.
