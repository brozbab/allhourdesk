# AllHourDesk Website Design Assets

This folder contains the visual direction, design system, component specifications and concept artwork for the next AllHourDesk website.

## Design objective

**Boutique hotel precision + enterprise software confidence.**

The website should look like a serious hospitality technology vendor: calm, premium, trustworthy and operationally credible. Product proof comes first; hospitality atmosphere supports it.

## Folder structure

- `DESIGN_SYSTEM.md` — visual rules, typography, colour, spacing and responsive behaviour
- `COMPONENTS.md` — reusable website component specifications
- `VISUAL_ASSET_MAP.md` — where each generated visual belongs and how it should be used
- `IMAGE_STYLE_GUIDE.md` — art direction for future generated visuals
- `design-tokens-vnext.css` — proposed implementation tokens for the redesign
- `visuals/` — web-optimised previews of the generated concept visuals

Related content strategy: `../website content/WEBSITE_CONTENT.md`.

## Important implementation rule

The visuals in `visuals/` are **concept/design references**, not canonical product screenshots. Text-heavy interfaces should ultimately be recreated as responsive HTML/CSS/SVG using real product data and approved copy. This keeps typography crisp, improves accessibility and prevents generated UI details from becoming accidental product claims.

## Initial visual set

2. Multilingual guest service
3. Integrations architecture
4. Trust and operational control
5. After-hours and overflow coverage

These establish the visual language for the rest of the website.
