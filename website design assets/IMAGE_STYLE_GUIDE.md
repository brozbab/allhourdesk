# AllHourDesk Image & Visual Style Guide

## Visual north star

**Premium hospitality software, not an AI poster.**

Every visual should combine:
1. believable product UI
2. warm hospitality context
3. restrained editorial sophistication
4. operational clarity

## Palette

- warm bone / ivory environment
- oxblood primary accents
- clay highlights on dark
- charcoal ink typography
- muted beige structural surfaces
- restrained green for success only

Avoid bright cyan, neon purple, sci-fi gradients and glossy 3D AI motifs.

## Composition

Preferred:
- generous whitespace
- one clear focal point
- structured UI cards
- fine connector lines
- subtle architecture or reception cues around the edges
- product state visible at a glance

Avoid:
- collage density
- giant decorative hotel photos
- floating unrelated icons
- generic dashboards with meaningless charts

## UI content

Use short believable labels:
- Incoming call
- Live Call
- Language detected
- PMS availability
- Room selected
- Payment link sent
- Payment received
- Reservation confirmed
- Escalated to team
- Connected

Use plausible sample data, clearly understood internally as illustrative.

## Hospitality cues

Good:
- reception bell
- understated marble/wood surfaces
- room thumbnail
- doorway/arch geometry
- luggage used sparingly
- warm hotel architectural detail

Avoid:
- staged call-centre agents
- headset stock photos
- obvious luxury-hotel clichés
- overly lavish resort imagery that changes the perceived target customer

## People

When people are needed:
- natural, contemporary hotel staff or travellers
- authentic working context
- no exaggerated poses
- no fake testimonial framing

## Product/UI assets

For production:
- recreate text-heavy visuals in HTML/CSS/SVG
- use raster/generated art mainly as art direction or supporting imagery
- keep real UI aligned with actual product capability
- never let generated UI invent a compliance certification or integration

## Motion guidance

For homepage hero:
1. call arrives
2. transcript appears
3. language resolves
4. availability returns
5. payment link state changes
6. confirmation becomes green

Use subtle opacity/translate transitions, 180–300ms.
No looping attention-grabbing animation.

## Prompt foundation for future concept art

Use this style direction:

> Premium B2B hospitality SaaS visual for AllHourDesk. Warm bone background, oxblood and clay accents, charcoal ink typography, elegant editorial serif influence, clean rounded software UI cards, fine connector lines, minimal shadows, subtle hotel architecture cues, software-first composition, calm enterprise credibility, no neon AI aesthetic, no robots, no generic call-centre stock imagery.

Then describe only the specific workflow required.
